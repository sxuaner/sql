在JVM中的可数循环
定义:
JVM对循环的一种优化技术，用于减少应用程序中安全点的数量，从而降低JVM的负担。
特点:
循环变量（索引）使用 int 或更小的数据类型。

----
使用 int 或更小的数据类型是什么意思？

“循环变量（索引）使用 int 或更小的数据类型”是指在 Java 虚拟机（JVM）优化的可数循环中，循环的索引变量必须是 int 类型或比 int 更小的数据类型（如 short、byte）。
这样 JVM 能更好地预测循环次数，并对这类循环进行优化（比如不插入安全点），提升性能。如果使用 long 或更大的类型，则不属于可数循环，JVM不会进行这种优化。
----

循环的执行次数被JVM认为次数不多，且在可预期的范围内。
优化方式:
JVM默认不为可数循环放置安全点，这意味着在循环执行过程中线程不会被频繁中断以便进行垃圾收集等操作。
与之相对:
使用 long 或更大范围数据类型作为索引值的循环，以及执行次数可能很大的循环，则被视为不可数循环，JVM会在这些循环处放置安全点。
影响:
可数循环的优化可以提高程序的性能，减少垃圾回收的暂停时间。
但在某些情况下，如果可数循环的实际执行时间过长，仍然可能导致子线程长时间无法进入安全点，影响主线程的响应。
相关参数:
可以通过JVM 参数 -XX:+UseCountedLoopSafepoints 来关闭对可数循环放置安全点的优化，强制所有循环都放置安全点。
其他可能含义(非技术术语)
虽然在技术语境中，“可数循环”主要指JVM的优化，但根据上下文也可能指代其他意思：
可回收物（可循环利用的物品）:
在垃圾分类领域，“可回收物”是一个常用的词，指那些回收后可以再加工成为原料的物品，如废纸、塑料、金属等。﻿
循环数（数学概念）:
指一类特殊的整数，其数字的循环排列恰好为其连续倍数的排列，例如142857就是著名的循环数。﻿
