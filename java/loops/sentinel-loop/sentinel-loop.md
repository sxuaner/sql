what is the opposite of counted loop
The opposite of a counted loop is a condition-controlled loop. 
Here's a breakdown of the key differences:
Counted loop (or counter-controlled loop)
Purpose: To repeat a specific number of times. The number of repetitions is known before the loop starts.
Controlling variable: A counter variable is used to track the number of iterations.
Example: A for loop that iterates from 1 to 10. The program knows it will run exactly 10 times. 
Condition-controlled loop (or sentinel-controlled loop)
Purpose: To repeat until a certain condition is no longer met. The number of repetitions is not known in advance.
Controlling variable: The loop continues as long as a specific condition evaluates to True. The loop terminates when a "sentinel" value or event is reached.
Examples:
A while loop that continues reading a file until it reaches the "end of file" marker.
A loop that keeps asking for user input until a positive number is entered
