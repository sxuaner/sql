Client-side TLS 1.2 enabled by default

In Java 8, client-side TLS 1.2 enabled by default means that when Java applications connect to secure servers (using HTTPS, SSL/TLS), they will use TLS version 1.2 by default for client connections. This improves security, as TLS 1.2 is more secure than older protocols like TLS 1.0 or SSL. You don’t need to manually configure your application to use TLS 1.2—it’s the default setting.
