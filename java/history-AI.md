# History of Java

Java was invented by James Gosling and his team at Sun Microsystems in 1991. Originally called **Oak**, then **Green**, the language eventually settled on the name **Java**. It was initially designed for interactive television but gained prominence with the rise of the internet. The first public version, **Java 1.0**, was released in 1996.

## Timeline

### Early Development (1991–1995)
- The project, initially known as Oak, was started by James Gosling, Mike Sheridan, and Patrick Naughton at Sun Microsystems.
- The team aimed to create a language for consumer electronic devices, particularly interactive TV.

### Name Change
- The name Oak was later changed to Java, inspired by Indonesian coffee, after discovering another company already used the name Oak.

### Java 1.0 (1996)
- The first public version was released, promising **"write once, run anywhere" (WORA)** functionality.

## Key Features
- Java's bytecode architecture and the Java Virtual Machine (JVM) allowed it to be platform-independent.

## Rise in Popularity
- Java quickly gained popularity, especially with the growth of the internet and the ability to embed Java applets in web browsers.

## Continuous Evolution
- Java has seen numerous updates and new versions, with ongoing development and new features being added.

## Impact
- Java remains a widely used language, powering applications across various domains, including web, mobile, enterprise, and games.
