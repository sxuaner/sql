# Java

**Java** is a **high-level**, **general-purpose**, **memory-safe**, **object-oriented** programming language. Its _"write once, run anywhere"_ (**WORA**) philosophy allows compiled Java code to run on any platform supporting Java, without recompilation. Java applications are compiled to **bytecode**, which executes on any **Java Virtual Machine** (**JVM**), independent of hardware architecture.

The syntax of Java resembles **C** and **C++**, but omits many low-level features. The runtime provides dynamic capabilities such as **reflection** and **runtime code modification**, which are uncommon in traditional compiled languages.

Java gained rapid popularity after its release in **1995** and remains widely used. In **2022**, it was the **third most popular language on GitHub**, though its usage has gradually declined as other **JVM-based languages** have grown in popularity.

Java was designed by **James Gosling** at **Sun Microsystems** and released in **May 1995**. Sun's original Java **compilers**, **JVMs**, and **class libraries** were proprietary, but most technologies were relicensed under **GPL-2.0-only** in **2007**. **Oracle** acquired Sun in **2010** and maintains the **HotSpot JVM**, while the official reference implementation is the open-source **OpenJDK JVM**, the default for most **Linux distributions**.

As of **March 2025**, **Java 24** is the current version. **Long-term support (LTS)** versions—**Java 8**, **11**, **17**, and **21**—remain under maintenance.


Is Java 24 LTS?
No, Java 24 is not a Long-Term Support (LTS) release. The latest LTS version is Java 21, and the next LTS release will be Java 25, expected in September 2025. Java 24 is a standard, non-LTS release, meaning it will receive shorter support from Oracle
